# Modèle LaTeX pour mémoire de Licence

Ce dépôt propose un modèle LaTeX pour faciliter la rédaction et la mise en forme des mémoires de Licence.

## Fonctionnalités

- Structure organisée du mémoire.
- Mise en forme cohérente des chapitres, figures, tableaux et équations.
- Code source personnalisable.
- Génération du document final au format PDF.

## Prérequis

- Une distribution LaTeX : TeX Live ou MiKTeX.
- Un éditeur LaTeX, tel que TeXstudio.

## Utilisation

1. Cliquez sur **Code → Download ZIP** pour télécharger les fichiers.
2. Extrayez l'archive dans un dossier local.
3. Ouvrez le fichier principal `.tex` avec TeXstudio.
4. Compilez le document pour générer le PDF.
5. Adaptez le modèle à votre mémoire.

Veillez à conserver tous les fichiers nécessaires à la compilation.
